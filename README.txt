Camera App Pro — APK-ready Android WebView project

This ZIP is prepared as an Android Studio/Gradle project.
- Camera and microphone permissions are declared and requested.
- WebView supports camera/video through getUserMedia.
- Photos are saved to Pictures/Camera App Pro using Android MediaStore.
- Videos are saved to Movies/Camera App Pro using Android MediaStore.
- Share uses the Android system share sheet.
- The HTML gallery/editor remains inside the app.
- Zoom rail is positioned lower than before.

Build: open this folder in Android Studio and build the debug APK.
If Android Studio asks to sync Gradle, allow it to download the Android Gradle Plugin and dependencies.
