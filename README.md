# CameraProFull — Android Native Camera

مشروع Android Native حقيقي باستخدام CameraX، وليس WebView.

## يعمل فعليًا
- Preview من كاميرا الجهاز
- التقاط الصور وحفظها في Pictures/CameraPro
- تسجيل الفيديو وحفظه في Movies/CameraPro
- تبديل الكاميرا الأمامية/الخلفية
- الفلاش
- المؤقت 0/3/10 ثوانٍ
- زوم 0.5×/1×/2×/3× (بحسب قدرات الجهاز)
- تركيز باللمس
- وضع Photo / Video / Portrait في الواجهة
- صلاحيات الكاميرا والميكروفون
- زر المعرض

## البناء
افتح المجلد في Android Studio ثم Sync/Build APK.
الملف يستخدم CameraX 1.4.2 ويحتاج اتصال إنترنت أول مرة لتنزيل Gradle والمكتبات.
لا توجد أيقونة أو اسم مخصص داخل المشروع حسب الطلب.
