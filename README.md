# Roblox Graphics Tool v4

Bản v4 sửa phần Giảm đồ họa:
- Không chỉ chạy một lệnh `cmd game mode battery`.
- Thử 2 cú pháp Game Mode tương thích.
- Hiển thị output/error thật trên màn hình để biết máy có hỗ trợ hay không.
- Giữ `performance` và `standard`.
- Tự nhận Roblox VN `com.roblox.client.vnggames` hoặc Roblox quốc tế `com.roblox.client`.

Lưu ý: Game Mode là tính năng Android/OEM. Nó không đảm bảo thay đổi thanh Graphics Quality bên trong Roblox trên mọi máy. Cần Shizuku đang chạy và cấp quyền cho app.
