# NovaChat Bluetooth FULL 2.0

نسخة Android أصلية لمحادثة خاصة بين هاتفين عبر Bluetooth Classic، بدون إنترنت وبدون خادم.

## المميزات
- محادثة نصية لحظية.
- اتصال مضيف/عميل.
- قائمة الأجهزة المقترنة + بحث Bluetooth.
- إرسال الصور.
- إرسال الملفات.
- تسجيل وإرسال رسائل صوتية AAC/M4A.
- تشغيل الرسائل الصوتية المستلمة.
- إشعارات للرسائل والملفات.
- اسم ملف شخصي محفوظ محليًا.
- وضع RTL عربي وتصميم هاتف.
- لوحة إدارة مخفية: اضغط شعار NovaChat 7 مرات.
- إخراج/قطع الاتصال.
- حظر جهاز Bluetooth وإلغاء الحظر.
- لا يتم إرسال البيانات إلى خادم.

## الاستخدام
1. ثبّت التطبيق على الهاتفين.
2. فعّل Bluetooth.
3. اعمل اقتران Pair للهاتفين من إعدادات Android.
4. الهاتف الأول: اضغط «استضافة».
5. الهاتف الثاني: اختر الهاتف الأول من القائمة واضغط «اتصال».
6. بعد ظهور «🟢 متصل» ابدأ المحادثة.
7. للصور والملفات استخدم 🖼 و 📎.
8. للتسجيل اضغط 🎤 ثم اضغط مرة ثانية للإيقاف والإرسال.

## ملاحظات Android
- في Android 12+ سيطلب التطبيق BLUETOOTH_SCAN/CONNECT/ADVERTISE.
- سيطلب RECORD_AUDIO عند استخدام الرسائل الصوتية.
- سيطلب POST_NOTIFICATIONS في Android 13+.
- بعض الأجهزة قد تحتاج تفعيل «الأجهزة القريبة» من إعدادات الصلاحيات.
- الملفات المستلمة تحفظ في مجلد التطبيق `received` داخل مساحة ملفات التطبيق.
- المشروع مصدر Android Studio؛ لا يحتوي APK جاهزًا.

## الخصوصية
الاتصال مباشر بين الهاتفين عبر Bluetooth. لا توجد قاعدة بيانات أو حسابات أو خادم.
