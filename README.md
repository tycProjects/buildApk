# Tai Video

App Android tải video đa nền tảng – giao diện sang trọng, logo thỏ dễ thương.

**Package:** `com.ryan.download` | **Min SDK:** 26

## Tính năng
- 1000+ trang (YouTube, TikTok, Instagram, X, Facebook…) nhờ yt-dlp
- Material 3 dark luxury + animation mượt
- Logo thỏ (ảnh bạn cung cấp)
- Tối ưu tốc độ: aria2c 16 connections + concurrent-fragments 8 + fallback
- Lịch sử persistent (Room)
- Share Intent + xin quyền tự động
- Lưu vào Downloads/TaiVideo

## Build
1. Giải nén → mở bằng Android Studio
2. Sync Gradle
3. Run

```bash
./gradlew assembleDebug
```
